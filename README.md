Python Calculator

A basic GUI calculator developed using Python and Tkinter.

Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Clear (AC)
- Delete (Del)
- Decimal calculations

Technologies Used
- Python
- Tkinter
  
How to Run
1. Install Python.
2. Download this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python calculator.py
```
